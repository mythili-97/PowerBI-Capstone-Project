# Retail Sales Analysis
Objective:
The objective of this project is to identify performance of chocolate retail business and identify key sales trends,high-performing regions and customer purchasing patterns.

## Description
Teh project involves data cleaning,transformation,analysis using microsoft Excel and visualization using Power BI,An interactive Power BI dashboard was created to convert raw sales data into meaningful business insights and support data-driven decision-making.

The key objectives of this project are:
*Analyze total sales performance over time.
*Track monthly, quarterly, and yearly sales trends.
*Identify regions with high and low sales performance.
*Analyze customer purchasing patterns.
*Identify sales trends and performance variations.
*Provide meaningful business insights through interactive dashboards.

Tools and Technologies:
-Microsoft Excel:Data cleaning,data transformation,sorting and filtering,pivot tables,basic data analysis.
-Power BI:Data Modeling,DAX measures,slicers and filters,interactive visualizations.

Project Workflow:
1. Data Collection:The raw chocolate retail sales dataset was used as the source data for the analysis.

2. Data Cleaning – Excel
The raw dataset was cleaned and prepared for analysis by:
*Checking for duplicate records.
*Handling missing/unknown values.
*Checking data types.
*Sorting and filtering the data.
*Preparing the dataset for analysis.

3. Data Transformation:
The cleaned dataset was transformed into a suitable structure for analysis.
The project includes:Fact table,Dimension table,YearMonth,Quarter with respective sales.
  
4. Excel Analysis:
A Pivot Table was created in Excel to perform initial analysis and understand the sales data before developing the Power BI dashboard.

5. Power BI Dashboard:The cleaned and prepared dataset was imported into Power BI.

Interactive visuals were created to analyze:
*Total Sales
*Sales by Year,Sales by Month,Sales by Quarter,Sales by Region
*Customer purchasing patterns
*Overall sales performance
*Slicers and filters were added to allow users to interact with the dashboard and analyze specific periods or regions.

 Dashboard Features:

The Power BI dashboard provides an interactive view of chocolate sales performance.

-Key KPIs
-Total revenue,Total Orders,Average price 
Visualizations,Monthly Sales Trend,Quarterly Sales Analysis,Yearly Sales Performance,Regional Sales Analysis
Customer Type,Salesperson
Interactive Features:Year slicer,Quarter slicer,Region filter,Interactive charts.
Business Insights:
-Identified overall sales performance and variations across different time periods.
-Compared quarterly and yearly sales performance to understand business trends.
-Identified high- and low-performing regions based on sales contribution.
-Examined customer purchasing patterns to understand customer behaviour.
-Developed an interactive Power BI dashboard to support data-driven business decisions.

Outcome:
This project demonstrates the complete data analytics workflow, starting from raw data and ending with an interactive business intelligence dashboard.
